# moonseek 项目申报书

**1、项目名称**

moonseek —— 纯 MoonBit 嵌入式全文搜索引擎

**2、项目简介**

moonseek 是一个完全用 MoonBit 编写的嵌入式全文搜索引擎库。它把「倒排索引 + BM25 排序 + 免词典中文分词 + 崩溃安全持久化」做进一个零 FFI 依赖的纯 MoonBit 核心，同一套代码编译到 native、WebAssembly、JavaScript 三端。使用者把文档喂给库，即可获得关键词、短语、前缀、字段限定、模糊容错与分面过滤检索，以及服务端高亮、逐词项分数解释与 WAL 崩溃恢复；索引可整体序列化为一份带 CRC 校验的快照，支持原子保存与重载。项目已发布 mooncakes 包 v0.6.0（259 项 native / 242 项 wasm-gc 测试全绿，`--deny-warn` 零告警；CI 除既有八矩阵外新增质量回归与新旧目标快照互通校验），并提供浏览器在线演示（GitHub Pages，WasmGC）：**直接在浏览器里搜索 mooncakes 全部 3,698 个真实包**。

项目还把检索质量做成可复现数据：`tools/eval` 在全量注册表上计算 NDCG@10 / MRR@10 / Recall@20 并产出 `docs/quality.md` 与消融表。关键结论——字段加权 NDCG@10 = 0.9045，等权重 0.8236，只搜包名 0.4082：加权比「子串搜索」高 122%；而 BM25 长度归一在该语料上是 −1.1%（噪声），报告如实写出。标注由语料结构派生（作者关键词 / 依赖边 / 包名），与检索器输出无关，故跨配置可比；报告声明其不可与 BEIR/MS MARCO 相比。

**3、项目方向，通用性说明**

方向：数据处理与数据库 / 基础工具库（填补 MoonBit 生态在全文检索基础设施上的空白）。

通用性：moonseek 不绑定任何应用场景或数据格式——检索能力以通用库 API 暴露（Index 建索引、Document 加文档、Query 查询语法、FacetFilter 过滤、Snapshot 序列化），字段模式由调用方声明。因此同一个库既能做服务端文档检索，也能做浏览器端离线搜索、本地知识库、代码检索或 RAG 召回底座；核心不依赖文件系统与网络（native 文件层单独可选），可被任意 MoonBit 项目作为依赖复用。

**4、至少 3 个完整的预期使用场景**

- **场景一：服务端文档/知识库检索**。MoonBit 后端服务把产品手册、FAQ、内部 Wiki 的万级文档写入 moonseek，用户查询经 BM25 排序返回命中片段与高亮，支持 `title:xx` 字段限定与分面过滤（按产品线、语言筛选）。索引以快照落盘，服务重启后加载恢复；写入过程经 WAL 保证崩溃不丢数据。
- **场景二：浏览器端零后端搜索（已完整落地）**。仓库内 `demo/` 是这一场景的**成品而非示意**：它索引 **mooncakes.io 上全部 3,698 个已发布包**（22,837 个版本）的包名、作者关键词、描述与依赖边。索引由**原生二进制**构建为 1.37 MB 的 `MSK3` 快照，再由**浏览器内的 wasm-gc 模块**直接加载——同一份字节格式跨两个后端。实测：快照加载 ~200 ms，12 条查询混合的中位延迟 **0.20 ms**，p90 0.2–0.3 ms，wasm 二进制 206 KB。同一页面还能拖入你自己的 `.txt/.md/.json/.csv/.log` 文件即时建索引，并把整个索引以单块快照持久化到 IndexedDB、刷新后无需重新解析即可恢复。
- **场景三：本地笔记与代码检索工具**。桌面工具（CLI/TUI）把笔记目录或代码库索引到本地快照，native 目标直接读写文件；增量写入先落 WAL 再进内存，异常退出后重放日志恢复；索引损坏可检测并拒绝加载，而非静默返回错误结果。仓库内 `tools/registry` 就是这一路径的真实用例。
- **场景四（延伸）：AI 应用的检索底座**。作为 RAG 流程的第一级召回：先用字段与分面做结构化过滤缩小候选集，再用 BM25 排序给出可解释的候选（逐词项 tf/df/idf 分解可用于调试召回质量），最后交给向量检索或 LLM 重排。

**5、拟实现的核心功能**

已完成：倒排索引与多字段加权；BM25 排序（k1/b 可配）；CJK 二元切分（免词典中文检索）；布尔 / 精确短语 / 松散短语（`"a b"~N`，最小跨度算法）/ 前缀 / 字段限定查询；模糊搜索（编辑距离 + BK-tree，2.4 万词项提速 17–491×）；拼写纠错（词频加权 did-you-mean）；分面过滤与聚合计数；服务端高亮与片段提取（码点级偏移）；逐词项 BM25 分数解释；排序控制与游标分页；段式索引与分层合并；WAL 预写日志崩溃恢复；CRC 校验快照（MSK3，兼容旧格式）；CLI 与浏览器演示。

**6、是否为原创项目、移植项目或参考已有开源项目**

原创项目，非移植。未复制任何第三方实现；算法（BM25、CJK bigram、BK-tree、WAL 帧格式）为公开文献的独立实现，代码全部自行编写。

**7、如为移植项目，需说明参考项目名称、来源链接和许可证**

不适用（原创项目）。项目依赖仅两个，均为 Apache-2.0 且仅使用未修改的公开 API：`moonbitlang/core`（标准库）、`moonbitlang/async`（仅用于 native 层文件读写）。项目自身以 Apache-2.0 开源。
