# moonseek 项目申报书

**1、项目名称**

moonseek —— 纯 MoonBit 嵌入式全文搜索引擎

**2、项目简介**

moonseek 是一个完全用 MoonBit 编写的嵌入式全文搜索引擎库。它把「倒排索引 + BM25 排序 + 免词典中文分词 + 崩溃安全持久化」做进一个零 FFI 依赖的纯 MoonBit 核心，同一套代码编译到 native、WebAssembly、JavaScript 三端。使用者把文档喂给库，即可获得关键词、短语、前缀、字段限定、模糊容错与分面过滤检索，以及服务端高亮、逐词项分数解释与 WAL 崩溃恢复；索引可整体序列化为一份带 CRC 校验的快照，支持原子保存与重载。项目已发布 mooncakes 包 v0.4.0（242 项测试全绿、八矩阵 CI 全绿）。

**3、项目方向，通用性说明**

方向：数据处理与数据库 / 基础工具库（填补 MoonBit 生态在全文检索基础设施上的空白）。

通用性：moonseek 不绑定任何应用场景或数据格式——检索能力以通用库 API 暴露（Index 建索引、Document 加文档、Query 查询语法、FacetFilter 过滤、Snapshot 序列化），字段模式由调用方声明。因此同一个库既能做服务端文档检索，也能做浏览器端离线搜索、本地知识库、代码检索或 RAG 召回底座；核心不依赖文件系统与网络（native 文件层单独可选），可被任意 MoonBit 项目作为依赖复用。

**4、至少 3 个完整的预期使用场景**

- **场景一：服务端文档/知识库检索**。MoonBit 后端服务把产品手册、FAQ、内部 Wiki 的万级文档写入 moonseek，用户查询经 BM25 排序返回命中片段与高亮，支持 `title:xx` 字段限定与分面过滤（按产品线、语言筛选）。索引以快照落盘，服务重启后加载恢复；写入过程经 WAL 保证崩溃不丢数据。
- **场景二：浏览器端零后端搜索**。把索引快照（数十 KB 至数 MB）与 WasmGC 模块一起打进前端，用户在文档站、帮助中心或电子书阅读器里搜索时**完全在本地完成**——无网络请求、无隐私外泄，且离线可用。仓库内 `demo/` 即该场景的可运行实例（60 篇中英文档，含中文分词与短语检索）。
- **场景三：本地笔记与代码检索工具**。桌面工具（CLI/TUI）把笔记目录或代码库索引到本地快照，native 目标直接读写文件；增量写入先落 WAL 再进内存，异常退出后重放日志恢复；索引损坏可检测并拒绝加载，而非静默返回错误结果。
- **场景四（延伸）：AI 应用的检索底座**。作为 RAG 流程的第一级召回：先用字段与分面做结构化过滤缩小候选集，再用 BM25 排序给出可解释的候选（逐词项 tf/df/idf 分解可用于调试召回质量），最后交给向量检索或 LLM 重排。

**5、拟实现的核心功能**

已完成：倒排索引与多字段加权；BM25 排序（k1/b 可配）；CJK 二元切分（免词典中文检索）；布尔 / 短语 / 前缀 / 字段限定查询；模糊搜索（Levenshtein/Damerau 编辑距离 + BK-tree 加速，2.4 万词项提速 13–1780×）；拼写纠错（词频加权 did-you-mean）；分面过滤与聚合计数；服务端高亮与片段提取（码点级偏移、HTML 转义）；逐词项 BM25 分数解释；排序控制与游标分页；段式索引与分层合并；WAL 预写日志崩溃恢复；CRC 校验快照（MSK3，兼容旧格式）；CLI 与浏览器演示。

**6、是否为原创项目、移植项目或参考已有开源项目**

原创项目，非移植。未复制任何第三方实现；算法（BM25、CJK bigram、BK-tree、WAL 帧格式）为公开文献的独立实现，代码全部自行编写。

**7、如为移植项目，需说明参考项目名称、来源链接和许可证**

不适用（原创项目）。项目依赖仅两个，均为 Apache-2.0 且仅使用未修改的公开 API：`moonbitlang/core`（标准库）、`moonbitlang/async`（仅用于 native 层文件读写）。项目自身以 Apache-2.0 开源。
